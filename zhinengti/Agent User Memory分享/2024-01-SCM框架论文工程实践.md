## 1. 背景与问题
### 1.1 现状问题
大语言模型（LLM）在处理长期对话时面临两个核心限制：

1. **输入长度限制**：大多数LLM的上下文窗口在4k-8k tokens之间，无法容纳长期对话的全部历史
2. **历史信息遗忘**：即使在上下文窗口内，LLM也容易被大量历史噪音干扰，遗忘关键信息

**典型失败案例**：

```
Day 1 (Turn 1):
User: 我最喜欢的运动是游泳、徒步和旅行
ChatGPT: 很好！这些都是健康的活动...

[500轮对话后，约10,000 tokens]

Day 20 (Turn 500):
User: 你还记得我最喜欢的运动吗？
ChatGPT: ❌ 我没有能力记住个人数据。如果你之前提到过，我现在也无法记住。
```
### 1.2 解决方案
本方案提出**Self-Controlled Memory (SCM)框架**，通过外置记忆系统和智能控制器，使LLM能够：

* ✅ 处理无限长度的对话历史
* ✅ 智能检索相关历史信息
* ✅ 动态决定使用原文或摘要
* ✅ 避免引入不必要的噪音

## 3. 核心流程描述
### 3.1 完整对话流程（以第500轮为例）
**场景设定**：

* 用户与AI已进行499轮对话
* 历史对话总计约10,000 tokens
* 用户在第1轮提到"喜欢游泳、徒步和旅行"
* 用户在第10轮说"计划开始跑步"
* 现在第500轮询问："你还记得我最喜欢的运动吗？"

#### 阶段一：输入获取与初步判断
**用户输入第500轮**：

```
User: 你还记得我最喜欢的运动吗？
```
系统接收输入后，立即进入第一个决策点：这个问题是否需要查阅历史记忆？

**记忆激活判断**：

记忆控制器使用预设的提示词模板，询问LLM：

```
给定一个用户指令，判断执行该指令是否需要历史信息或者上文的信息，
或者需要回忆对话内容。只需要回答是(A)或者否(B)，不需要解释：

指令：你还记得我最喜欢的运动吗？

答案：
```
**LLM判断结果**：`是(A)` ✓

判断逻辑：

* 关键词"还记得"→ 明确表示需要历史信息
* "我最喜欢的运动"→ 需要回溯个人偏好信息
* 结论：激活记忆检索流程

如果是"给我讲个笑话"这样的指令，控制器会返回`否(B)`，直接跳到响应生成，节省检索开销。

#### 阶段二：记忆检索与评分排序
**启动双维度检索**：

系统从记忆流中检索所有499轮历史记忆，对每条记忆计算两个维度的得分：

**1. 相关性得分（Relevance Score）**

首先，将用户问题转换为嵌入向量：

```python
query = "你还记得我最喜欢的运动吗？"
query_embedding = text-embedding-ada-002(query)  # 768维向量
```
然后，计算与每条历史记忆的余弦相似度：

```
记忆1（第1轮）:
  存储的嵌入向量: embedding_1（由"用户喜欢游泳、徒步、旅行"生成）
  相关性 = cosine_similarity(query_embedding, embedding_1)
        = 0.92  ← 高度相关！

记忆10（第10轮）:
  存储的嵌入向量: embedding_10（由"用户计划开始跑步"生成）
  相关性 = cosine_similarity(query_embedding, embedding_10)
        = 0.85  ← 较相关

记忆499（第499轮）:
  存储的嵌入向量: embedding_499（由"今天天气真好"生成）
  相关性 = cosine_similarity(query_embedding, embedding_499)
        = 0.23  ← 不相关
```
**2. 时效性得分（Recency Score）**

使用指数衰减函数，优先考虑最近的对话：

```
记忆1（第1轮，距今499轮）:
  时效性 = 0.99^499 = 0.007  ← 非常旧

记忆10（第10轮，距今490轮）:
  时效性 = 0.99^490 = 0.008  ← 很旧

记忆499（第499轮，距今1轮）:
  时效性 = 0.99^1 = 0.99  ← 最新
```
**3. 综合排序**

将两个得分相加得到最终排名分数：

```
记忆1:  rank_score = 0.92 (相关性) + 0.007 (时效性) = 0.927
记忆10: rank_score = 0.85 (相关性) + 0.008 (时效性) = 0.858
记忆499: rank_score = 0.23 (相关性) + 0.99 (时效性) = 1.22

排序结果：
1. 记忆499 (score=1.22) ← 虽然不相关，但最新
2. 记忆1 (score=0.927)  ← 高度相关
3. 记忆10 (score=0.858) ← 较相关
```
**检索结果（Top-3）**：

由于记忆499与问题无关（天气话题），在后续的内容重组阶段会被过滤。实际保留：

```
Activation Memory（激活记忆，长期记忆）:
- 记忆1: "用户喜欢游泳、徒步和旅行"
- 记忆10: "用户计划开始跑步锻炼"
  
Flash Memory（闪存记忆，短期记忆）:
- 记忆499: "用户：今天天气真好 / 助手：是的，很适合户外活动"
```
Flash Memory固定为上一轮（T-1）对话，用于保持对话的即时连贯性。

#### 阶段三：记忆重组与压缩
检索出的记忆可能非常冗长，系统需要决定使用原文还是摘要。

**统计token数量**：

```
记忆1完整内容: 
  用户："我最喜欢的运动是游泳、徒步和旅行，我觉得..."（600 tokens）
  助手："这很棒！游泳是一项全身运动..."（400 tokens）
  总计：1000 tokens

记忆10完整内容:
  用户："我计划开始规律地锻炼，想从跑步开始..."（800 tokens）
  助手："这是一个很好的开始！你计划多久跑一次？..."（500 tokens）
  总计：1300 tokens

总计：2300 tokens > 2000 tokens阈值
```
**触发摘要判断**：

对于超过800 tokens的单条记忆，控制器询问LLM：

```
给定对话内容和用户问题，请回答命令问题。

对话内容：
用户："我计划开始规律地锻炼，想从跑步开始..."
助手："这是一个很好的开始！你计划多久跑一次？..."

用户问题：你还记得我最喜欢的运动吗？

命令问题：基于对话内容，用户问题能否仅用对话摘要回答？
回答(A)可以 或 (B)不可以。

答案：
```
**LLM判断结果**：`(A)可以`

控制器决定使用该记忆在存储时已生成的摘要：

```
记忆10摘要版本：
  "用户计划开始跑步锻炼。助手询问跑步频率。"（20 tokens）
```
**最终重组结果**：

```
Activation Memory（长期记忆）:
  [记忆1-完整] 用户："我最喜欢的运动是游泳、徒步和旅行..." (1000 tokens)
  [记忆10-摘要] "用户计划开始跑步锻炼。助手询问跑步频率。" (20 tokens)

Flash Memory（短期记忆）:
  [记忆499-完整] 用户："今天天气真好" / 助手："是的，很适合..." (150 tokens)

总计：约1170 tokens ✓ 成功压缩！
```
#### 阶段四：输入融合与提示构造
将重组后的记忆与当前问题融合成完整的提示词：

```
这是用户和AI助手的对话。请根据历史对话回答当前问题：

历史对话：
[第1轮]
用户：我最喜欢的运动是游泳、徒步和旅行，我觉得这些活动既能锻炼身体，
     又能让我接触大自然，非常享受这种感觉。
助手：这很棒！游泳是一项全身运动，可以增强心肺功能；徒步让你探索户外；
     旅行则开阔视野。这三项活动的组合非常均衡！

[第10轮摘要]
用户计划开始跑步锻炼。助手询问跑步频率。

上一轮对话：
用户：今天天气真好
助手：是的，很适合户外活动！

###
用户：你还记得我最喜欢的运动吗？
助手：
```
**关键设计**：

* "历史对话"区：放置长期相关记忆（Activation Memory）
* "上一轮对话"区：放置短期连贯记忆（Flash Memory）
* 使用`###`分隔符明确区分历史与当前

#### 阶段五：LLM生成响应
LLM基于融合后的输入生成回答：

```
助手：是的，我记得！你最喜欢的运动是游泳、徒步和旅行。你特别喜欢这些
     活动能让你接触大自然的特点。另外，你在第10天还提到计划开始跑步
     锻炼，这也是一项很好的运动选择。
```
**响应质量分析**：

* ✅ 准确回忆第1轮的信息（游泳、徒步、旅行）
* ✅ 关联第10轮的补充信息（跑步计划）
* ✅ 保持对话自然流畅
* ✅ 没有被无关的历史噪音干扰

#### 阶段六：记忆更新与存储
生成响应后，将当前轮对话存入记忆流：

**1. 生成当前轮摘要**

使用摘要生成提示词：

```
以下是用户和AI助手的一段对话，请分别用一句话写出用户摘要、助手摘要：

对话内容：
用户：你还记得我最喜欢的运动吗？
助手：是的，我记得！你最喜欢的运动是游泳、徒步和旅行...

摘要：
```
LLM生成：

```
用户摘要：用户询问AI是否记得其喜欢的运动。
助手摘要：助手回忆用户喜欢游泳、徒步、旅行，并提及用户的跑步计划。
```
**2. 生成嵌入向量**

```python
summary_text = "用户询问AI是否记得其喜欢的运动。助手回忆用户喜欢游泳、徒步、旅行，并提及用户的跑步计划。"
embedding_500 = text-embedding-ada-002(summary_text)  # 768维向量
```
**3. 存储到记忆流**

```python
memory_item_500 = {
    "interaction_index": 500,
    "observation": "你还记得我最喜欢的运动吗？",
    "system_response": "是的，我记得！你最喜欢的运动是游泳、徒步和旅行...",
    "memory_summarization": {
        "user_summary": "用户询问AI是否记得其喜欢的运动",
        "assistant_summary": "助手回忆用户喜欢游泳、徒步、旅行，并提及跑步计划"
    },
    "interaction_embedding": embedding_500,
    "timestamp": "2024-10-22T10:30:00Z"
}

# 存入Redis（快速访问）
redis.hset("memory:500", mapping=memory_item_500)

# 存入Pinecone（语义检索）
pinecone.upsert(id="500", values=embedding_500, metadata={...})
```
至此，第500轮对话完整处理完毕。系统现在拥有500轮的完整记忆，可以继续处理后续对话。

### 3.2 流程总结
整个流程可以概括为**"六步循环"**：

1. **输入获取** - 接收用户问题
2. **记忆激活判断** - 决定是否需要检索历史
3. **记忆检索排序** - 双维度评分找出最相关记忆
4. **记忆重组压缩** - 决定使用原文或摘要，控制输入长度
5. **输入融合** - 将记忆与当前问题组合成提示词
6. **生成响应并存储** - LLM生成回答，更新记忆流

这个循环在每一轮对话中重复，使系统能够持续学习和记忆。

### 3.3 关键设计理念
**为什么这个方案有效？**

1. **选择性记忆**：不是把所有历史都塞给LLM，而是智能检索最相关的部分
2. **双重记忆机制**：

    * Activation Memory（长期）：根据相关性和时效性动态检索
    * Flash Memory（短期）：固定保留上一轮，维持对话连贯性

3. **动态压缩**：根据需要使用摘要，在信息完整性和输入长度间平衡
4. **自我控制**：由LLM自己判断何时需要记忆、如何使用记忆，避免硬编码规则

**与传统方案的对比**：

|方案|输入长度|信息完整性|噪音干扰|
|-|-|-|-|
|直接截断前N轮|固定|❌ 丢失关键信息|⚠️ 中等|
|全量历史摘要|固定|⚠️ 摘要可能丢失细节|❌ 包含大量无关信息|
|SCM框架|动态|✅ 检索最相关信息|✅ 智能过滤噪音|

## 4. 详细设计
### 4.1 记忆流设计
#### 4.1.1 数据模型
**MemoryItem结构**：

```python
from dataclasses import dataclass
from typing import Dict, Optional
import numpy as np
from datetime import datetime

@dataclass
class MemoryItem:
    """单条记忆项的完整数据结构"""
    
    # 基础标识
    interaction_index: int              # 对话轮次索引（1, 2, 3, ...）
    timestamp: datetime                 # 创建时间戳
    
    # 对话内容
    observation: str                    # 用户原始输入
    system_response: str                # AI原始响应
    
    # 摘要信息
    memory_summarization: Dict[str, str]  # {'user_summary': '...', 'assistant_summary': '...'}
    
    # 嵌入向量
    interaction_embedding: np.ndarray   # 768维向量（text-embedding-ada-002）
    
    # 元数据
    tokens_count: int                   # 总token数（observation + response）
    conversation_id: Optional[str]      # 会话ID（支持多用户）
    tags: Optional[list]                # 标签（如：['运动', '个人偏好']）
    
    # 检索统计
    access_count: int = 0               # 被检索次数
    last_access_time: Optional[datetime] = None  # 最后访问时间
```

```python
class MemoryController:
    """记忆控制器：决策中枢"""
    
    def __init__(self, llm_client, memory_stream):
        self.llm = llm_client
        self.memory_stream = memory_stream
        
        # 参数配置
        self.config = {
            "top_k": 5,                    # 检索Top-K记忆
            "recency_decay": 0.99,         # 时效性衰减因子
            "summary_threshold": 800,      # 单条记忆摘要阈值（tokens）
            "total_threshold": 2000,       # 总记忆摘要阈值（tokens）
            "max_context_tokens": 3000     # 最大上下文长度
        }
    
    def process(self, observation: str, current_turn: int, 
                conversation_id: str) -> Dict:
        """
        处理当前观察，返回需要的记忆
        
        Returns:
            {
                "needs_memory": bool,
                "activation_memory": List[MemoryItem],
                "flash_memory": MemoryItem,
                "reorganized_memory": str
            }
        """
        # Step 1: 判断是否需要激活记忆
        needs_memory = self.check_memory_necessity(observation)
        
        if not needs_memory:
            return {
                "needs_memory": False,
                "activation_memory": [],
                "flash_memory": None,
                "reorganized_memory": ""
            }
        
        # Step 2: 检索记忆
        activation_memory = self.retrieve_memories(
            query=observation,
            current_turn=current_turn,
            conversation_id=conversation_id,
            top_k=self.config["top_k"]
        )
        
        # Step 3: 获取Flash Memory（固定为T-1轮）
        flash_memory = self.memory_stream.get(
            conversation_id=conversation_id,
            turn=current_turn - 1
        )
        
        # Step 4: 重组记忆（决定使用原文或摘要）
        reorganized = self.reorganize_memories(
            activation_memory=activation_memory,
            flash_memory=flash_memory,
            query=observation
        )
        
        return {
            "needs_memory": True,
            "activation_memory": activation_memory,
            "flash_memory": flash_memory,
            "reorganized_memory": reorganized
        }
```

#### 4.2.3 记忆检索算法
**双维度评分函数**：

```python
def calculate_recency_score(self, memory_turn: int, current_turn: int) -> float:
    """
    计算时效性得分（指数衰减）
    
    Args:
        memory_turn: 记忆的轮次索引
        current_turn: 当前轮次索引
    
    Returns:
        [0, 1]范围的得分，越近得分越高
    """
    distance = current_turn - memory_turn
    decay_factor = self.config["recency_decay"]  # 0.99
    
    recency_score = decay_factor ** distance
    
    return recency_score


def calculate_relevance_score(self, query_embedding: np.ndarray, 
                              memory_embedding: np.ndarray) -> float:
    """
    计算相关性得分（余弦相似度）
    
    Args:
        query_embedding: 查询的嵌入向量 (768,)
        memory_embedding: 记忆的嵌入向量 (768,)
    
    Returns:
        [0, 1]范围的得分，越相关得分越高
    """
    # 余弦相似度
    dot_product = np.dot(query_embedding, memory_embedding)
    norm_query = np.linalg.norm(query_embedding)
    norm_memory = np.linalg.norm(memory_embedding)
    
    cosine_sim = dot_product / (norm_query * norm_memory)
    
    # 归一化到[0, 1]（原始范围是[-1, 1]）
    relevance_score = (cosine_sim + 1) / 2
    
    return relevance_score


def retrieve_memories(self, query: str, current_turn: int,
                     conversation_id: str, top_k: int = 5) -> List[MemoryItem]:
    """
    检索最相关的记忆
    
    算法：rank_score = recency_score + relevance_score
    """
    # 1. 生成查询嵌入
    query_embedding = self.generate_embedding_for_query(query)
    
    # 2. 从Pinecone检索候选记忆（语义相似）
    candidate_results = self.memory_stream.vector_search(
        query_vector=query_embedding,
        namespace=conversation_id,
        top_k=50  # 先检索50个候选
    )
    
    # 3. 计算双维度得分
    scored_memories = []
    
    for result in candidate_results:
        memory_turn = result['metadata']['interaction_index']
        memory_embedding = np.array(result['values'])
        
        # 计算得分
        recency = self.calculate_recency_score(memory_turn, current_turn)
        relevance = self.calculate_relevance_score(query_embedding, memory_embedding)
        
        rank_score = recency + relevance
        
        # 从Redis获取完整记忆内容
        memory_item = self.memory_stream.get(
            conversation_id=conversation_id,
            turn=memory_turn
        )
        
        scored_memories.append({
            "memory": memory_item,
            "recency_score": recency,
            "relevance_score": relevance,
            "rank_score": rank_score
        })
    
    # 4. 按rank_score排序
    scored_memories.sort(key=lambda x: x['rank_score'], reverse=True)
    
    # 5. 返回Top-K
    top_memories = [item['memory'] for item in scored_memories[:top_k]]
    
    return top_memories
```
**检索流程示意**：

```
查询："你还记得我最喜欢的运动吗？"（第500轮）

Step 1: 生成查询嵌入
  query_embedding = [0.031, -0.022, 0.048, ...]

Step 2: 向量检索（Pinecone）
  candidate_results = [
    {id: "1", similarity: 0.92, metadata: {turn: 1, ...}},
    {id: "10", similarity: 0.85, metadata: {turn: 10, ...}},
    {id: "150", similarity: 0.78, metadata: {turn: 150, ...}},
    ...（共50个）
  ]

Step 3: 计算双维度得分
  记忆1 (turn=1, 距今499轮):
    recency = 0.99^499 = 0.007
    relevance = (0.92 + 1) / 2 = 0.96
    rank_score = 0.007 + 0.96 = 0.967
  
  记忆10 (turn=10, 距今490轮):
    recency = 0.99^490 = 0.008
    relevance = (0.85 + 1) / 2 = 0.925

  记忆150 (turn=150, 距今350轮):
    recency = 0.99^350 = 0.030

    rank_score = 0.030 + 0.89 = 0.920

Step 4: 排序
  排序结果 = [记忆1, 记忆10, 记忆150, ...]
```

**重组主函数**：

```python
def reorganize_memories(self, activation_memory: List[MemoryItem],
                       flash_memory: MemoryItem, query: str) -> str:
    """
    重组记忆：决定使用原文还是摘要
    
    规则：
    1. 总tokens > 2000时，考虑使用摘要
    2. 单条记忆 > 800 tokens时，判断是否可用摘要
    3. Flash Memory通常使用完整内容
    
    Returns:
        格式化的记忆文本，用于输入融合
    """
    # 1. 统计总token数
    total_tokens = sum(m.tokens_count for m in activation_memory)
    
    reorganized_activation = []
    
    # 2. 判断是否需要压缩
    if total_tokens > self.config["total_threshold"]:  # 2000
        # 需要压缩
        for memory in activation_memory:
            if memory.tokens_count > self.config["summary_threshold"]:  # 800
                # 大记忆：判断是否可用摘要
                can_use_summary = self.check_summary_sufficiency(memory, query)
                
                if can_use_summary:
                    # 使用摘要
                    content = (
                        f"[第{memory.interaction_index}轮摘要]\n"
                        f"{memory.memory_summarization['user_summary']}\n"
                        f"{memory.memory_summarization['assistant_summary']}"
                    )
                else:
                    # 使用完整内容
                    content = (
                        f"[第{memory.interaction_index}轮]\n"
                        f"用户：{memory.observation}\n"
                        f"助手：{memory.system_response}"
                    )
            else:
                # 小记忆：直接使用完整内容
                content = (
                    f"[第{memory.interaction_index}轮]\n"
                    f"用户：{memory.observation}\n"
                    f"助手：{memory.system_response}"
                )
            
            reorganized_activation.append(content)
    else:
        # 不需要压缩，全部使用完整内容
        for memory in activation_memory:
            content = (
                f"[第{memory.interaction_index}轮]\n"
                f"用户：{memory.observation}\n"
                f"助手：{memory.system_response}"
            )
            reorganized_activation.append(content)
    
    # 3. 组装最终文本
    history_text = "\n\n".join(reorganized_activation)
    
    # 4. 添加Flash Memory
    if flash_memory:
        flash_text = (
            f"用户：{flash_memory.observation}\n"
            f"助手：{flash_memory.system_response}"
        )
    else:
        flash_text = ""
    
    # 5. 返回格式化文本
    reorganized = f"""
历史对话：
{history_text}

上一轮对话：
{flash_text}
""".strip()
    
    return reorganized
```

```python
class LLMAgent:
    """LLM代理：负责生成响应"""

        """
        生成响应
        
        Args:
            prompt: 完整的输入提示词（包含记忆和当前问题）

                {"role": "user", "content": prompt}

        )
```

```python
class SCMFramework:

    def __init__(self):
        self.llm_agent = LLMAgent(model_name="gpt-3.5-turbo")
        self.memory_stream = MemoryStream()
        self.memory_controller = MemoryController(
            llm_client=self.llm_agent,
            memory_stream=self.memory_stream

                    current_turn: int) -> str:

        处理一轮对话
        
        Args:
            user_input: 用户输入
            conversation_id: 会话ID
            current_turn: 当前轮次
        
        Returns:
            AI响应

        memory_result = self.memory_controller.process(
            observation=user_input,
            current_turn=current_turn,
            conversation_id=conversation_id
        )

                reorganized_memory=memory_result["reorganized_memory"],
                current_input=user_input

            # 不需要记忆，直接使用当前输入

        # Step 4: 生成响应
        response = self.llm_agent.generate(final_prompt)
        
        # Step 5: 存储当前轮记忆
        self.save_memory(
            conversation_id=conversation_id,
            turn=current_turn,
            observation=user_input,
            response=response
        )
        
        return response

                   observation: str, response: str):

        # 生成摘要
        summary = self.generate_summary(observation, response)
        
        # 生成嵌入
        embedding = self.generate_embedding(summary)
        
        # 创建记忆项

            interaction_index=turn,
            timestamp=datetime.now(),
            observation=observation,
            system_response=response,
            memory_summarization=summary,
            interaction_embedding=embedding,
            tokens_count=count_tokens(observation + response),
            conversation_id=conversation_id
        )
        
        # 存储
        self.memory_stream.add(memory_item)
```

## 5. 关键算法
### 5.1 记忆检索算法伪代码
```
ALGORITHM: Memory Retrieval with Dual-Dimension Scoring

INPUT:
  - query: 用户当前输入
  - current_turn: 当前轮次T
  - conversation_id: 会话ID
  - top_k: 返回Top-K记忆（默认5）
  - decay_factor: 时效性衰减因子（默认0.99）

OUTPUT:
  - top_memories: List[MemoryItem]，Top-K最相关记忆

PROCEDURE:
1. query_embedding ← GenerateEmbedding(query)

2. candidates ← VectorSearch(
     query_vector=query_embedding,
     namespace=conversation_id,
     top_k=50  // 先检索50个候选
   )

3. scored_memories ← []

4. FOR EACH candidate IN candidates DO:
     memory_turn ← candidate.metadata.interaction_index
     memory_embedding ← candidate.values
     
     // 计算时效性得分
     time_distance ← current_turn - memory_turn
     recency_score ← decay_factor ^ time_distance
     
     // 计算相关性得分（余弦相似度）
     dot_product ← DotProduct(query_embedding, memory_embedding)
     norm_query ← Norm(query_embedding)
     norm_memory ← Norm(memory_embedding)
     cosine_sim ← dot_product / (norm_query * norm_memory)
     relevance_score ← (cosine_sim + 1) / 2  // 归一化到[0,1]
     
     // 计算总分
     rank_score ← recency_score + relevance_score
     
     // 获取完整记忆内容
     memory_item ← GetMemory(conversation_id, memory_turn)
     
     scored_memories.APPEND({
       memory: memory_item,
       recency_score: recency_score,
       relevance_score: relevance_score,
       rank_score: rank_score
     })
   END FOR

5. // 按rank_score降序排序
   scored_memories.SORT(key=rank_score, reverse=True)

6. // 返回Top-K
   top_memories ← scored_memories[0:top_k].memory

7. RETURN top_memories

END PROCEDURE
```
### 5.2 记忆重组算法伪代码
```
ALGORITHM: Memory Reorganization (Summary Selection)

INPUT:
  - activation_memory: List[MemoryItem]，激活的长期记忆
  - flash_memory: MemoryItem，短期记忆（T-1轮）
  - query: 用户当前问题
  - summary_threshold: 单条摘要阈值（默认800 tokens）
  - total_threshold: 总体摘要阈值（默认2000 tokens）

OUTPUT:
  - reorganized_text: str，重组后的格式化文本

PROCEDURE:
1. total_tokens ← SUM(m.tokens_count FOR m IN activation_memory)

2. reorganized_items ← []

3. IF total_tokens > total_threshold THEN:
     // 需要压缩
     FOR EACH memory IN activation_memory DO:
       IF memory.tokens_count > summary_threshold THEN:
         // 大记忆：判断是否可用摘要
         can_use_summary ← CheckSummarySufficiency(memory, query)
         
         IF can_use_summary THEN:
           content ← FormatSummary(memory)  // 使用摘要
         ELSE:
           content ← FormatFullContent(memory)  // 使用完整内容
         END IF
       ELSE:
         // 小记忆：直接使用完整内容
         content ← FormatFullContent(memory)
       END IF
       
       reorganized_items.APPEND(content)
     END FOR
   ELSE:
     // 不需要压缩，全部使用完整内容
     FOR EACH memory IN activation_memory DO:
       content ← FormatFullContent(memory)
       reorganized_items.APPEND(content)
     END FOR
   END IF

4. // 组装历史对话文本
   history_text ← JOIN(reorganized_items, separator="\n\n")

5. // 添加Flash Memory
   IF flash_memory IS NOT NULL THEN:
     flash_text ← FormatFullContent(flash_memory)
   ELSE:
     flash_text ← ""
   END IF

6. // 格式化最终文本
   reorganized_text ← f"""
   历史对话：
   {history_text}
   
   上一轮对话：
   {flash_text}
   """

7. RETURN reorganized_text

END PROCEDURE

// 辅助函数
FUNCTION CheckSummarySufficiency(memory, query):
  prompt ← f"""
  对话内容：{memory.observation}\n{memory.system_response}
  用户问题：{query}
  问题：用户问题能否仅用对话摘要回答？(A)可以 (B)不可以
  """
  response ← LLM.Generate(prompt)
  RETURN 'A' IN response OR '可以' IN response
END FUNCTION

FUNCTION FormatSummary(memory):
  RETURN f"""
  [第{memory.interaction_index}轮摘要]
  {memory.memory_summarization.user_summary}
  {memory.memory_summarization.assistant_summary}
  """
END FUNCTION

FUNCTION FormatFullContent(memory):
  RETURN f"""
  [第{memory.interaction_index}轮]
  用户：{memory.observation}
  助手：{memory.system_response}
  """
END FUNCTION
```

#### 6.3.1 嵌入缓存
```python
class EmbeddingCache:
    """嵌入向量缓存，避免重复计算"""
    
    def __init__(self, redis_client):
        self.redis = redis_client
        self.cache_prefix = "embedding:cache:"
    
    def get(self, text: str) -> Optional[np.ndarray]:
        """获取缓存的嵌入"""
        key = self.cache_prefix + hashlib.md5(text.encode()).hexdigest()
        cached = self.redis.get(key)
        
        if cached:
            return np.frombuffer(cached, dtype=np.float32)
        return None
    
    def set(self, text: str, embedding: np.ndarray):
        """缓存嵌入"""
        key = self.cache_prefix + hashlib.md5(text.encode()).hexdigest()
        self.redis.setex(
            name=key,
            time=86400 * 7,  # 7天过期
            value=embedding.astype(np.float32).tobytes()
        )
```

```python
def batch_retrieve(self, queries: List[str], conversation_id: str,

            query_embedding=query_embeddings[i],

        )
```

#### 6.3.3 异步处理
```python
import asyncio
from concurrent.futures import ThreadPoolExecutor

class AsyncSCMFramework:
    """异步版本SCM框架"""
    
    def __init__(self):
        self.executor = ThreadPoolExecutor(max_workers=10)
    
    async def process_turn_async(self, user_input: str, 
                                 conversation_id: str,
                                 current_turn: int) -> str:
        """异步处理对话"""
        
        # 并行执行多个任务
        tasks = [
            self.check_memory_necessity_async(user_input),
            self.get_flash_memory_async(conversation_id, current_turn - 1)
        ]
        
        necessity, flash_memory = await asyncio.gather(*tasks)
        
        if necessity:
            # 检索记忆
            activation_memory = await self.retrieve_memories_async(
                query=user_input,
                conversation_id=conversation_id,
                current_turn=current_turn
            )
            
            # 重组记忆
            reorganized = await self.reorganize_memories_async(
                activation_memory, flash_memory, user_input
            )
            
            # 生成响应
            response = await self.generate_async(reorganized, user_input)
        else:
            response = await self.generate_async("", user_input)
        
        # 异步保存记忆
        asyncio.create_task(
            self.save_memory_async(conversation_id, current_turn, 
                                  user_input, response)
        )
        
        return response
```

### 7.1 论文实验结果
基于论文Table 2的数据：

|多轮准确率|**75.0%**|64.3%|49.4% ↓25.6|74.8% ↓0.2|0.0% ↓75.0|

**测试数据集**：

* 105个问题（49个单轮相关，56个多轮相关）
* 18个长期对话实例
* 最大34k tokens，200轮对话

### 7.2 关键观察
1. **Activation Memory是核心**：去除后准确率从77.1%降到10.5%，召回率从94.0%降到0.0%
