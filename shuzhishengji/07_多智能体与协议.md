# 07 多智能体协作与协议（25 题）

1. 【高频】为什么需要多智能体？单 Agent 解决不了什么问题？
2. 【高频】多智能体有哪些协作模式（主从/Supervisor、流水线、辩论、群聊）？
3. 【专家】Supervisor 模式下，主 Agent 怎么决定把任务派给哪个子 Agent？
4. 多智能体之间的消息格式怎么设计？
5. 【高频】多智能体系统怎么避免互相"踢皮球"或无限对话？
6. AutoGen、CrewAI、MetaGPT 的设计思路分别是什么？
7. 【专家】多智能体系统的成本和延迟通常是单 Agent 的数倍，怎么判断值不值得？
8. 【高频】A2A（Agent2Agent）协议是什么？解决什么问题？
9. A2A 中 Agent Card、Task、Message、Artifact 分别是什么？
10. 【高频】A2A 和 MCP 的区别和关系是什么？
11. 【专家】ANP（Agent Network Protocol）的设计思路是什么？去中心化身份（DID）在其中起什么作用？
12. 跨组织的 Agent 互相调用，身份认证和信任怎么建立？
13. 多 Agent 并行执行时，共享状态怎么保证一致性？
14. 【专家】多人（多用户）与多个数字人同时对话，调度策略怎么设计？
15. 多人对话中，如何决定由哪个 Agent 回复、是否需要回复？
16. 调度命中率怎么统计？用 query 维度还是 session 维度？
17. 【高频】多智能体系统怎么调试？怎么定位是哪个 Agent 出了问题？
18. 子 Agent 失败时，主 Agent 怎么处理（重试、换 Agent、降级）？
19. 多智能体的任务结果怎么汇总，避免信息冲突？
20. 【专家】用 k8s 控制器（reconcile）模式管理 Agent 任务，有什么好处？
21. 多 Agent 系统中，工具和权限怎么按角色隔离？
22. 【高频】多智能体系统的评估和单 Agent 评估有什么不同？
23. Agent 市场 / Agent 商店怎么做发现、计费和质量控制？
24. 人类在多 Agent 协作中扮演什么角色？什么时候需要人工介入？
25. 【专家】设计一个支持 A2A 的 Agent 网关，需要考虑哪些功能？
