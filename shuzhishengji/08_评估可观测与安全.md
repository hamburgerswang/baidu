# 08 Agent 评估、可观测与安全（35 题）

## 评估
1. 【高频】Agent 的效果怎么评估？离线评估和在线评估分别看什么？
2. 【高频】LLM-as-a-Judge 怎么做？有哪些偏差（位置偏差、长度偏差、自我偏好）？
3. 【专家】如何证明 LLM 评审的结果可信？和人工评估一致性怎么衡量？
4. 评测集怎么构造？怎么保证覆盖度和代表性？
5. 【高频】badcase 怎么收集、分类和闭环？
6. Agent 的任务成功率怎么定义和统计？
7. 【专家】多步 Agent 的过程评估（轨迹评估）怎么做？
8. 【高频】Agent 上线前的 AB 实验怎么设计？指标怎么选？
9. 满意度、session 维度、query 维度的指标各说明什么？
10. 【专家】端到端评估（如音视频数字人的形象、声音、口型）怎么设计指标体系和打分规则？
11. 人工质检怎么分配任务？交叉质检时分数不一致怎么合并？

13. 机器质检和人工质检怎么结合？
14. 评估平台需要哪些核心能力？
