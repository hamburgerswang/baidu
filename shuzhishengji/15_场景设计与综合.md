# 15 场景设计与综合（35 题）

## Agent 场景设计
1. 【高频】设计一个支持千万日活的智能客服 Agent 系统。
2. 【高频】设计一个企业内部知识问答助手（支持权限、引用、更新）。
3. 【专家】设计一个 Coding Agent，能读代码库、改代码、跑测试。
4. 设计一个能自动写周报的 Agent（数据来源：代码提交、文档、日程）。
5. 【专家】设计一个 Deep Research Agent，输出带引用的研究报告。
6. 设计一个电商导购 Agent，能推荐商品并挂载商品卡片。
7. 【高频】设计一个实时语音交互的数字人 Agent，端到端延迟控制在 1 秒内。
8. 【专家】设计一个支持上万个第三方开发者的智能体开放平台。
9. 设计一个 Agent 评测平台，支持数据集管理、自动评测、人工质检。
10. 设计一个数据分析 Agent（自然语言查数据库、出图表）。
11. 【专家】设计一个 Agent 任务调度平台，支持长任务、断点续跑、人工审批。
12. 设计一个多模态内容生产流水线（文案 → 配音 → 视频）。
13. 【高频】设计一个大模型 API 网关，支持多供应商、限流、计费、降级。
14. 设计一个对话数据的埋点、存储和分析系统。
15. 【专家】设计一个商业化归因系统：衡量一个 query 通过什么内容给哪个 Agent 带来了多少商业价值。

## 线上问题处理
16. 【高频】Agent 服务突然大量超时，你的排查步骤是什么？
17. 模型供应商故障，整个 Agent 不可用，怎么快速止损？
18. 【高频】某个 Agent 被用户诱导输出了违规内容，怎么处理？
19. 线上数据库 CPU 打满，怎么快速定位和止损？
20. Redis 突然大量超时，可能有哪些原因？
21. 发布后错误率上升，怎么判断是否回滚？
22. 【专家】上线后发现一批数据被写错了，怎么修复且不影响线上？

## 技术决策与管理
23. 【高频】在两个技术方案之间做选择时，你会考虑哪些因素？
24. 【高频】怎么评估一个技术方案的风险？
25. 业务需求紧急，但技术方案有隐患，你怎么处理？
26. 【专家】多个团队联合开发一个需求，你怎么推进和协调？
27. 技术债怎么识别和偿还？
28. 你怎么做代码评审？关注哪些点？
29. 【高频】怎么写一份好的技术评审文档？
30. 怎么带新人？怎么做技术分享和沉淀？
31. 【专家】AI 编程工具（Copilot、Cursor、Claude Code）对团队研发流程有什么影响？你怎么用？
32. 【专家】你怎么看 Agent 技术未来 1 到 2 年的发展方向？
33. 如果业务方案效果不及预期，你怎么用数据说服产品调整方向？
34. 【专家】专家和高级工程师的区别是什么？你认为自己已经具备了哪些专家能力？
35. 你下一年的技术规划是什么？
