## 题目与答案

每个题目文件都在 `题目与答案/` 目录下有一份同名文件，题目和参考答案放在一起。第 16 部分的答案以你本人的口吻写，文档中没有记录的内容标注为"【文档未记录，需本人确认】"，改进方向标注为"【可补充的改进思路】"。

## 建议的复习顺序

1. **先看第 16 部分**：领导最可能从你自己的项目切入，答不上自己项目的追问最减分。
2. **再看 03、05、09、15**：这几部分最能体现 Agent 专家能力，也和你做过的智能体平台、数字人、PaaS 工作直接相关。
3. **然后是 10、12、13、14**：后端基础题容易被追问细节，先过【高频】，再过【专家】。
4. **最后补 01、02、04、06、07、08、11**。

答题时尽量用自己项目里的例子。比如问到缓存一致性，可以讲「最近使用」接口的 Redis 加 MySQL 双写；问到批量查询和 N+1，可以讲 agent-mount 优化；问到大表删除，可以讲 20T 对话数据的冷备和删除。
